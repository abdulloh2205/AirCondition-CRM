# AirCondition CRM

CRM-система для компании по установке, обслуживанию и ремонту кондиционеров и вентиляции.

## Основные возможности:
- **Управление заявками**: Канбан-доска и таблица с фильтрами (монтаж, чистка/ТО, ремонт, бренд, BTU, этаж, автовышка).
- **Клиентская база**: карточки клиентов, адреса объектов, история всех обращений.
- **Календарь и задачи**: график выездов мастеров, дедлайны и статусы выполнения.
- **Аналитика для руководителя**: выручка, упущенная выгода при отменах, география по районам, рейтинг мастеров.
- **Экспорт в Excel**: быстрая выгрузка заявок, базы клиентов и финансовых отчетов.

## Запуск проекта:
```bash
npm install
npm run dev
```
